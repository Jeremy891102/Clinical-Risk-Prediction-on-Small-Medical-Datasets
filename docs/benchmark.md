# Protocol, evidence, and reproduction

## Ownership and objective

Jeremy Hsu independently implemented the data preparation, model pipelines,
experiments, and analysis for this NYU DS-GA 1003 project. The benchmark asks
whether a tabular foundation model improves prediction on small clinical datasets.

## Evaluation protocol

- **Datasets:** Heart (303 × 13), Pima (768 × 8), Breast Cancer (569 × 30),
  Liver (583 × 10), CKD (400 × 24). Dimensions are samples × input features.
  [Dataset summary](../results/tables/dataset_comparison.csv) and
  [data loaders / target definitions](../src/data/loaders.py).
- **Models:** Logistic Regression, SVM, Random Forest, MLP, XGBoost,
  CatBoost, and TabPFN.
- **Main evaluation:** seed 42; stratified 10-fold outer CV. Tuned baselines use
  stratified 5-fold inner GridSearchCV scored by AUROC. TabPFN uses its default
  configuration without inner hyperparameter search.
- **Preprocessing:** imputation, numeric scaling, and categorical encoding are
  fitted within the CV pipeline. [Implementation](../src/evaluation/nested_cv.py).
- **Displayed scores:** unweighted means of the 10 outer-fold scores, recomputed
  and checked against each archived JSON aggregate. They are not pooled
  out-of-fold metrics. AUROC is higher-is-better; Brier is lower-is-better.
- **Robustness check:** Heart and Pima, seeds 0, 1, 7, 42. Random Forest and
  CatBoost use reduced grids for seeds 0/1/7, centered on seed-42 winners;
  seed 42 uses the full grid. Other models keep their original search setup.
  This mixes search budgets and is not a pure split-seed comparison.
  [Grid definitions](../scripts/task3_multi_seed.py) ·
  [original full grids](../results/grid_sizes.md).

## Reading the results

- TabPFN leads mean AUROC on Heart, Pima, and Breast Cancer. CKD is saturated:
  several methods have AUROC 1.0. CatBoost leads Liver (0.7618 vs 0.7603).
- TabPFN has the lowest mean Brier score on every dataset. Brier measures overall
  probability quality, not calibration alone. By ECE, SVM leads Heart and
  XGBoost leads Pima. [Calibration results](../results/tables/ece_per_model.csv).
- Friedman omnibus tests across the seven models and five datasets give
  p=0.06406 for AUROC and p=0.02235 for Brier. The latter indicates an
  across-model difference; it does **not** demonstrate that TabPFN significantly
  beats every baseline. Five datasets provide limited statistical power.
  [Statistical analysis](../scripts/task1_friedman_cd.py) ·
  [pairwise Brier p-values](../results/tables/friedman_nemenyi_brier.csv).
- Sample-size ablation and feature/error analyses remain available as
  [existing figures](../figures/). The ablation reuses selected hyperparameters
  and is not a fresh nested-CV experiment at every sample size; see
  [its protocol](../scripts/task6_sample_ablation.py).
- These are retrospective public-dataset experiments, not prospective or
  external clinical validation. Results do not establish deployment readiness.

## Figure provenance

The README figures are generated by
[`scripts/plot_readme_results.py`](../scripts/plot_readme_results.py):

- `benchmark.png`: 35 JSON runs from [`results/raw/`](../results/raw/), seed 42.
  Outlined cells identify the best mean within a dataset, including numerical ties.
  Values are rounded for display; selection uses unrounded scores.
- `stability.png`: the 14 relevant seed-42 runs plus 42 runs from
  [`results/raw_multi_seed/`](../results/raw_multi_seed/). Small dots show each
  seed's 10-fold mean; large dots and bars show the four-seed mean ± sample SD.
  Panel x-axis ranges differ. Bars are not confidence intervals.
- The script checks run identities, fold coverage, score bounds, saved aggregates,
  dataset sample counts, and agreement with the existing rounded multi-seed summary.
  It does not train models, fetch patient-level data, or download checkpoints.

The figures summarize committed experiment outputs. They do not represent new
training runs or a newly validated software environment. The archived score JSONs
do not fully capture dependency/checkpoint provenance; the current code selects
TabPFN v2.5, but that alone does not independently verify the historical checkpoint.

## Reproduction

Use Python 3.11 or 3.12 and install `requirements.txt` in a virtual environment.
The README chart script needs only NumPy and Matplotlib from those requirements:

```bash
pip install "numpy>=1.26,<2.0" "matplotlib>=3.8"
python scripts/plot_readme_results.py
```

To run experiments after installing the full requirements:

```bash
python experiments/run_smoke_test.py
python experiments/run_nested_cv.py --model logistic_regression --dataset heart
python experiments/run_nested_cv.py --model all --dataset all --seed 42
pytest tests/ -k "not tabpfn"
```

- Dataset loaders require network access to UCI/OpenML on the first run.
- TabPFN v2.5 weights require a valid Prior Labs license/API token supplied
  outside the repository, e.g. `TABPFN_TOKEN` or `tabpfn.browser_auth.save_token`.
  Do not commit tokens or downloaded checkpoints. `pytest tests/` includes
  TabPFN tests requiring that access.
- XGBoost may require OpenMP (`libomp.dylib`) on macOS.
- Maintained code lives in `src/data/`, `src/models/`, and `src/evaluation/`.
  `scripts/task*.py` contain additional analyses. Top-level `run.py` and legacy
  `src/*.py` files are early planning stubs.
- The final course report is maintained separately in Overleaf; a public report
  PDF is not included here.
- Historical verification recorded on 2026-05-08: the non-TabPFN subset had
  39 passed, 2 deselected. This is a historical record, not a claim that the
  experiment suite was rerun for the README update.
